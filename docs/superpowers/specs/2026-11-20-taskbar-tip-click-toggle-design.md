# 任务栏统计信息气泡点击切换 设计文档（2026-11-20）

## 意图与原因

任务栏窗口的统计信息提示当前是"悬停显示、移开消失"（标准 tooltip 行为），数值停留时间
最长约 32 秒。希望改为**点击控制**：左键点击弹出，移开鼠标不关闭，再次点击关闭，循环切换，
便于持续观察统计信息。

## 目标 / 非目标 / 反目标

- **目标**：任务栏窗口左键点击（非插件区域）切换统计气泡显示/隐藏；气泡常驻且内容每秒刷新；
  右键菜单弹出、窗口销毁时自动收起；双击功能保持不变。
- **非目标**：不改浮动主窗口的鼠标提示；不改任务栏双击动作；不加新设置项
  （现有"显示鼠标提示"开关作为总开关：关闭时点击不弹）。
- **反目标**：悬停自动弹出与点击切换共存（逻辑冲突，已与用户确认取消悬停弹出）。

## 约束

- 主程序为 MFC 项目（硬依赖），构建需 VS "MFC for v143" 组件（本机当前缺失，构建方式另行确认）
- 气泡样式沿用现有 `CToolTipCtrl` 外观，不引入新窗口类
- 行为仅作用于任务栏窗口 `CTaskBarDlg`

## 方案比较（已由用户确认方案 A）

- **方案 A（选定）**：tooltip 切换到 tracking 模式（`TTF_TRACK`+`TTM_TRACKACTIVATE`/`TTM_TRACKPOSITION`）。
  显示/隐藏完全由程序控制，移开鼠标不消失；样式不变；改动集中在 `CTaskBarDlg`，无新窗口类。
- **方案 B（否决）**：自绘弹出窗口。可控性相同但需要新窗口类、绘制/焦点/任务栏交互全自理，成本高无收益。
- **方案 C（否决）**：`TTDT_AUTOPOP` 调到最大值（32 秒）。无法实现"常驻直到再点击"，不满足需求。

## 行为定义

1. **触发**：`OnLButtonUp`（非插件显示区域；插件区域点击仍分发给插件，不切换气泡）。
   当前未显示 → 在点击点上方（任务栏窗口坐标系内计算屏幕位置）弹出；已显示 → 关闭。
2. **取消悬停弹出**：`PreTranslateMessage` 不再把鼠标消息 `RelayEvent` 给 tooltip；
   tooltip 初始化保留 `TTS_ALWAYSTIP` 并在 `AddTool` 时加 `TTF_TRACK`（MFC `AddTool` 带 `nFlags` 参数）。
   `TTDT_AUTOPOP` 等 hover 延迟设置不再需要。
3. **内容刷新**：现有定时 `UpdateToolTips()`/`UpdateTipText` 保留——tracking 模式下文本更新即时生效；
   已显示时数值每秒变化可见。
4. **自动收起**：右键菜单弹出处（现有 `Pop()` 调用点）改为关闭 tracking 气泡；窗口销毁时 tooltip
   随之销毁。
5. **双击**：保留现有双击动作；双击前的两次单击会导致气泡状态切换两次（回到原状态，视觉闪烁
   约 0.5 秒），已与用户确认可接受。
6. **show_tool_tip=false** 时：点击不弹气泡（若当前已显示则关闭）。

## 已知取舍

- 双击时的气泡闪烁（见行为定义第 5 条）。
- 悬停不再自动显示（用户要求的交互本身）。
- 气泡位置按点击点计算，任务栏窗口移动（自动隐藏任务栏）时不跟随——气泡由系统 tooltip
  承载，任务栏窗口重建（explorer 重启）时 tooltip 重建，气泡不会残留悬挂。

## 留给实现者的决定

- `TTM_TRACKPOSITION` 的具体偏移量（在点击点上方贴任务栏上沿，避免遮挡任务栏文字）
- 弹出状态的成员变量命名与既有代码风格对齐

## 验收

- 本机 Release x64 构建成功（需 MFC 组件）
- 真机：左键点击弹气泡 → 移开鼠标不消失且数值每秒刷新 → 再点关闭；右键菜单时气泡收起；
  双击功能正常；`显示鼠标提示`开关关闭时点击无反应
